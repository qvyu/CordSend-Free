## Notes
Use Python 3.10.12 for the best performance. 
## Installation

### Windows

```bash
# Clone the repository
git clone https://github.com/qvyu/CordSend-Free
cd CordSend-Free

# Create virtual environment
python -m venv venv

# Activate the environment
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run CordSend
python CordSend-Free.py
```
### Mac/Linux
```bash
# Clone the repository
git clone https://github.com/yourusername/CordSend.git
cd CordSend

# Create virtual environment
python3 -m venv venv

# Activate the environment
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run CodeSend
python3 CordSend-Free
```
